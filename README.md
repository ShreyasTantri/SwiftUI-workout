# SwiftUI Workout 🏋️‍♂️

This repository is my **daily SwiftUI practice gym**.

The goal is simple:

> Make SwiftUI UI design and thinking **second nature**.

No tutorials. No copy-paste apps.
Just **consistent hands-on practice** inside **one SwiftUI project**.

---

## 🎯 Purpose

* Become **confident and independent** in SwiftUI
* Design screens **without relying on AI or tutorials**
* Build strong **UI + state + layout intuition**
* Practice SwiftUI the way **real apps are built**

This repo is not about finishing an app.
It is about **building instincts**.

---

## 🧱 Project Structure Philosophy

* **One SwiftUI App**
* **Many Swift files** inside the same project
* Each Swift file represents:

  * One UI concept
  * One layout pattern
  * One real-world screen idea

No heavy folder structure initially.
Refactoring will be done **later**, when patterns are clear.

---

## 🧠 What I Practice Here

### 1️⃣ SwiftUI Basics

* Text styling & hierarchy
* Fonts, colors, spacing
* Modifiers order & effects

### 2️⃣ Layout Mastery

* VStack / HStack / ZStack
* Spacer-based layouts
* Alignment & frame behavior
* Screen vs component backgrounds

### 3️⃣ Reusable UI Components

* Card designs
* Custom rows
* Buttons & labels
* Empty state views

### 4️⃣ State-Driven UI (Core Focus)

* Empty / Loading / Error / Success states
* Enum-based screen states
* UI as a function of state

### 5️⃣ User Interaction

* Buttons & gestures
* Toggles & counters
* Form inputs
* Validation feedback

### 6️⃣ Real App Screens (Upcoming)

* Login screen
* Profile screen
* Lists with custom rows
* NavigationStack
* Settings UI

### 7️⃣ SwiftUI Architecture (Gradually)

* @State
* @Binding
* @StateObject / @ObservedObject
* MVVM-style separation

## 🔁 Daily Practice Rule

Every day:

1. Create **one new SwiftUI file**
2. Build UI **from scratch**
3. Focus on **one concept only**
4. Switch `ContentView` to test it
5. Commit with a clear message

Consistency > complexity.

---

## 🧪 How to Run

* Open the project in Xcode
* Open `ContentView.swift`
* Replace the body with the view you want to practice

Example:

```swift
struct ContentView: View {
    var body: some View {
        CardDesign01()
    }
}
```
